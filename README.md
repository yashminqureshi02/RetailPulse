RetailPulse – Customer Analytics & Sales Dashboard

Project Overview

RetailPulse is a data analytics project built to explore retail transactions, understand customer purchasing behaviour, and visualize sales performance.

Features

- Retail transaction data cleaning
- Sales KPIs and daily sales trends
- Top-selling products and countries
- Customer segmentation using RFM-style features and K-Means clustering
- Filtered transaction data and CSV download

Technology Stack

- Python
- Pandas
- Streamlit
- Plotly
- Scikit-learn

Dataset

This project uses the UCI Online Retail dataset. The original dataset should be placed at "data/raw/Online Retail.xlsx".

Run Locally

1. Install the required packages:
   "python -m pip install -r requirements.txt"
2. Clean the dataset:
   "python src/data_cleaning.py"
3. Start the dashboard:
   "python -m streamlit run app.py"

Project Status

The dashboard and analysis features should be tested locally before submission. Any feature that has not been successfully tested should not be considered complete.
